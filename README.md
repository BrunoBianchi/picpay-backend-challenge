# PicPay Backend Challenge

Money-transfer REST API inspired by the PicPay backend challenge — TypeScript + Node.js on a modelled relational schema.

## What it does

- Create users and wallets
- Transfer money between accounts with validation rules
- Persist operations on a clear relational model

## Stack

- TypeScript · Node.js
- Relational database (modelled schema)
- REST API

## Why this repo

Shows how I approach fintech-style backend problems: domain rules, schema design and a clean API surface.

## Getting started

```bash
npm install
npm run start
```
